# assets

图标、字体（思源宋体 Noto Serif SC，OFL）、Material Symbols（Apache 2.0）、已解锁底图（Natural Earth，公有领域，从 Electron 版 admin.js 转换）、示例计划和季节表模板。每项来源和授权都要写进 设置 → 关于。

## 现有文件

| 文件 | 内容 | 来源 / 授权 |
|---|---|---|
| `admin/adm1.geojson` | 省 / 州（4596 个，带 bbox、中文名），"已解锁"底图和地球离线简图用 | Natural Earth 10m admin-1，公有领域；从 Electron v6.3.0 `app/vendor/admin.js` 原样转出（7.0.0-b） |
| `admin/adm0.geojson` | 国界线（MultiLineString） | Natural Earth 50m admin-0，公有领域；同上 |
| `app/icon.ico` | 程序图标（exe、托盘、窗口、安装程序） | 1.3.2 换成「暮色」：从 `app/logo/icon.ico` 复制（Claude 原创，PO 定稿） |
| `app/icon-256.png` | 同上，256×256 PNG（窗口图标；欢迎页、关于页从资源里读） | 1.3.2 从 `app/logo/png/icon-256.png` 复制 |
| `app/logo/` | 图标母版 `dusk.svg`、16–32 px 简化版 `dusk-small.svg`、`png/` 各尺寸、`icon.ico`、横排字标 `lockup-*.png` | Claude 原创（1.3.2），方案页 https://claude.ai/artifact/UZiHvkHj89hxKpguukBmxH ；不打进安装包 |
| `fonts/MaterialSymbolsRounded.ttf` | 地图标记的图标字体（Material Symbols Rounded 子集，199 个图标；打包进程序资源，不单独复制） | Google Material Symbols，Apache 2.0；从 Electron v6.3.0 `app/vendor/fonts/material-symbols-rounded.woff2` 用 fontTools 原样转成 TTF（0.8.2） |
| `fonts/LICENSE-Material-Symbols.txt` | 上面字体的授权文本（原样复制，阶段 ⑧ 装进安装目录） | 同上 |
- `licenses/`：不在别处的授权全文（suncalc），编译时复制到程序目录的 `LICENSES\`（0.12.5）。
- `rail/`（1.3.0）：21 座城市的火车 / 地铁 / 轻轨 / 电车线路（每城一个 encoded polyline 文本 + `cities.txt`），打包进资源 `:/rail/`。来源 OpenStreetMap，© OpenStreetMap 贡献者，ODbL；由 `tools/rail-data.py` 生成（格式见脚本开头）。
