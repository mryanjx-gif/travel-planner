# tests

逻辑单元测试（Qt Test），不依赖界面。CMake 选项 TP_BUILD_TESTS=ON 时编译。

- `tst_data.cpp`：数据层（0.3.0；0.5.0 加自动保存节拍、撤销栈、备份）。在 Windows 上用根目录的 `单元测试.bat` 编译并运行。
- `golden/`：JSON 读写的基准文件（Node `JSON.stringify` 的输出），由 `tools/claude-kit/json-bench/gen.js` 生成，不要手改。
- 环境变量 `TP_ROUNDTRIP_DIRS`（多个用 ; 分隔）：额外做往返比对的数据文件夹，只读。
- `tst_app.cpp`：程序层（0.4.0）：设置文件、数据文件夹的选择和新建、Electron 设置读取、窗口位置纠正、翻译词典、**缺英文检查**（扫描 qml/ 和 src/ 里所有 `qsTr("…")` / `tp::tr("…")` / 数据层的 `trd("…")`，没有英文就不通过）、备份设置（0.5.0）、日志截断、出错报告（0.5.1：错误码和 Electron 一致、去掉路径、忽略规则、同码一次 / 最多 3 个）、上次崩溃的记号和转储只留 3 个、卡住检测计数、崩溃时 SEH 接哪些异常码（0.5.2）。`单元测试.bat` 两个都跑。

0.6.0：tst_data 的保存流程测试改成 travel.json；新增格式版本、锁、从 Electron 导入（样例逐字段、完整导入和再导入、取消回滚、只加新的、真实数据"每个值都找得到"、真实数据完整导入）。`testdata/travel.json` 由 `TP_WRITE_TESTDATA=1 tst_data importRealData` 生成。

0.7.0：`tst_photo.cpp`（EXIF、方向 8 种、缩略图、旋转、猜计划、复制 / 回滚、查重复、清理），测试照片打包在 `photos.txt`（每行"文件名<Tab>base64"，`tools/claude-kit/gen_photo_fixtures.py` 生成，期望值和 exiftool 一致；运行时解到临时文件夹。不直接放图片：写回 PO 电脑时图片会被加上 C2PA 内容凭证）。云端可加 `TP_EXIF_REAL=<exiftool -j -n 的输出>` 和真实照片逐张对照。`单元测试.bat` 三个都跑。

0.8.0：`tst_map.cpp`（投影和相机、像素换算跨 180° 经线、以光标为中心缩放、上下约束、1000 km 最小缩放、按范围缩放、maplibre-gl 飞行曲线、大圆弧、昼夜阴影叠层和多边形覆盖、"已解锁"和 Electron 逐个省对照、路线和 JS 数字规则）。`golden/unlock-colors.json` 由 `tools/claude-kit/unlock-golden/gen.js` 用 Electron 的原样代码算 `testdata/data.js` 生成，不要手改。`单元测试.bat` 四个都跑。

0.8.2：tst_map 加标记样式、尺寸、合并圆圈的颜色、分层、错开，以及和 Electron 逐组对照（`golden/marker-clusters.json`：`tools/claude-kit/marker-golden/gen.js` 用 Electron 原样的 applyClusters / stopStyle 算 `testdata/data.js` 的 0–6 级，不要手改；Electron 改了这段代码时重新生成）。

0.8.4：tst_map 加道路路线（`golden/roads.json`：`tools/claude-kit/road-golden/gen.js` 用 Electron 原样的 decodePolyline / encodePolyline / simplifyPts / legKeyOf 和 toFixed 算的，不要手改）、"还没算"的段和写回、OSRM 返回值、路线分三份。新增 `tst_net.cpp`：统一请求通道（本机 127.0.0.1 上临时开的假服务器：User-Agent、白名单、离线 / 服务开关、同一主机的最小间隔、超时、4xx 照样给内容、连不上、请求方没了不回调）和批量算道路路线（模拟的路线服务：写回、自动保存、记住算不出来的段、停止）。`单元测试.bat` 五个都跑。

0.8.5：tst_net 加硬盘缓存（上限、按时间删、旧瓦片、清空、后台清点、不认识的文件不动）和本机瓦片服务（命中不联网、同一张合并请求、路径检查、上游 500 / 不是图片 / 404、离线 503 不算失败、预取上限和并发、长连接 / HEAD / 别的方法）。tst_map 加预取的瓦片和 Electron 原样代码逐个对照（`golden/prefetch.json`：`tools/claude-kit/tile-golden/gen.js` 生成，不要手改）、手动标记用到的搜索 / 整组判断 / 副标题。

0.8.7：tst_map 加计划的排序、筛选（含 revealPlan、存取）、"此刻"和 Electron 原样代码逐项对照（`golden/plans.json`：`tools/claude-kit/plans-golden/gen.js` 用 Electron map-app.js / mapfirst.js 原样的 comparePlans / filterMatches / revealPlan / pickNow / todayItems / todos / notices 算 `testdata/data.js` 加几处人为改动，输入也写在文件里；不要手改，Electron 改了这几段时重新生成），简易面板内容、改数据、"已解锁"不看筛选；昼夜阴影细带不漏不叠、相邻两条透明度差 < 2%。
