# i18n

界面翻译（0.4.0 起，PO 2026-11-02：不用 lupdate / lrelease，不生成 .ts / .qm）。

- 界面文字在 QML 里写 `qsTr("中文")`，在 C++ 里写 `tp::tr("中文")`；键就是中文原文，可以带 `%1` 占位符。
- 英文来自 `tr/`：
  - `tr/electron-v6.3.0/b1–b26.txt`：Electron 版词典原样（共 1974 条，和 app/js/i18n-en.js 一致）。按文件名字典序合并、后面的覆盖前面的（和 Electron 的 build_dict.py 一样）。很多是句子碎片，只有和原生版整句完全相同时才会用上。
  - `tr/native.txt`：原生版新加的句子（`中文<Tab>英文`，`\n` 表示换行，`#` 开头是注释），同一句以它为准。
- 这些文件打包进程序资源，运行时由 `src/app/translator.*`（`DictTranslator`）直接读取；设置 → 通用 → 语言切换后立即生效。
- **检查**：`tests/tst_app.cpp` 的 `allStringsTranslated` 扫描 `qml/` 和 `src/` 里所有 `qsTr("…")` / `tp::tr("…")`，有一句没有英文就不通过（`单元测试.bat` 会跑）。新加或修改界面文字时同时补 `native.txt`。
