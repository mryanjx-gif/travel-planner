# 旅行计划 原生版（TravelPlanner Native）

Windows 桌面旅行规划软件：地图优先的界面（平面地图 + 地球），计划、想去、足迹、照片、日历、游记、账本、AI 助手，行程单导出和安装程序。Qt 6（C++/QML）+ maplibre-native-qt，Win10/11 64 位，中英双语。

这个项目由一位 PO 和 Claude（Claude Code）在 9 天里从 Electron 版重写而来，代码全部由 Claude 写。
