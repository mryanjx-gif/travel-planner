# Travel Planner 旅行计划

Windows 桌面旅行规划软件：以世界地图为主界面，排行程、记想去的地方、点亮去过的地方。中英双语，免费，支持 Win10/11 64 位。

## 设计大纲

**界面**：地图铺满窗口，平面地图和 3D 地球之间可以切换，面板用半透明玻璃浮在地图上。

| 模块 | 内容 |
|---|---|
| 地图模式 | 计划（计划中）、想去、足迹（去过 + 点亮省份国家）、照片 |
| 计划 | 站点和路线、每日行程、交通住宿、行李待办、攻略、天气和气候、地点介绍 |
| 钱 | 消费记录、多币种汇率、同行人分账、全部旅程的账本 |
| 记录 | 相册、日历（年 / 月 / 周）、游记 |
| AI 助手 | 接入 Claude、DeepSeek 等，对话改计划、引导式规划、从订单生成交通住宿 |
| 导出 | 行程单 PDF、.trip 计划文件、安装程序和便携版 |

**数据**：存在本地 JSON 文件里，没有服务器；保存前备份、写入后回读校验、保留历史版本，可以导入旧版数据。

**联网**：底图、地名搜索、路线、天气、汇率都用免费服务，可以一键离线。

**技术**：C++20 + Qt 6（QML）、maplibre-native-qt 画地图、自写着色器画地球，Vulkan / OpenGL。

第三方授权见程序里"设置 → 关于"。
