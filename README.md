# 旅行计划（Travel Planner）

一个 Windows 电脑上的旅行规划软件：打开就是一张世界地图（也能切成可以转动的地球），在上面排行程、记想去的地方、点亮去过的省份和国家；还有照片、日历、游记、记账和分账、AI 帮忙排行程，能导出行程单，有安装程序。中英双语，免费。

**这个仓库更想分享的是它是怎么做出来的**：作者不写代码，只负责提需求、做选择；全部代码（约 9 万行）、测试、界面设计、打包都由 AI 编程助手 Claude（通过 Claude Code）完成，从开工到 1.4.0 用了 9 天。

## 背景

作者之前已经用 Electron（用网页技术做桌面软件的框架）做过一版旅行计划。这一版改用 Qt（一套用 C++ 写桌面软件的工具）从头重写，做成直接跑在 Windows 上的软件，不再套着一个浏览器：功能和旧版对齐，再往前改进。程序文件名里的 "Native"（原生）指的就是这一点。

## 技术和授权

C++20、Qt 6.12（按 LGPL-3 动态链接）、maplibre-native-qt（地图）、自写的地球着色器。用到的第三方库、字体、地图和数据的来源和授权见程序里"设置 → 关于"和 [claude/技术选型.md](claude/技术选型.md)。编译环境见 [claude/Windows开发环境安装.md](claude/Windows开发环境安装.md)。

仓库里去掉了作者的真实旅行数据，依赖它的部分单元测试会跳过或失败。
