# qml/components

共用组件：液态玻璃、泡泡菜单、命令面板、标记、弹出卡等。

0.4.0：`GlassPanel`（简化版玻璃，阶段 ⑥ 换成液态玻璃）、`TpButton`、`ModalLayer`（对话框外壳）、`ChoiceDialog` + `ChoiceCard`（用选项卡片回答，冲突弹框方案 B、数据文件夹选择）、`MessageDialog`、`TextInputDialog`、`ExtChangedCard`（外部修改提示，方案 B）、`Banner`（只读 / 更新版本）、`Toast`、`Segmented`。

0.5.1：`ErrorCard`（出错小框，方案 B；在 Main.qml 的 `bottomCards` 里和 `ExtChangedCard` 叠在一起）。

0.7.0：`PhotoImportReview`（导入确认表，独立组件，跟着 `photos.importStage` 自己出现）、`PhotoCleanupDialog`（清理没用的照片）、`TpSelect`（下拉选择，列表放到窗口最上层）、`TpCheck`（勾选框）。

0.8.2：`MapMarkers`（站点标记、合并圆圈）、`MapTip`（地图上的提示框）。

0.8.4：`RoadBar`（"有 N 段还没算"提示条，Main.qml 顶部横幅那一列里）。

0.8.5：`LayerBubbles`（右上角图层按钮 + 分裂出来的 4 颗底图泡泡）、`UnlockPanel`（"已解锁"的足迹框和手动标记面板）。

0.8.7：`StatusFilterPill`（左下状态胶囊 + 筛选按钮）、`FilterMenu`（筛选下拉）、`NowCard`（"此刻"卡片，方案 B）、`PlanSheet`（简易计划面板，方案 C）、`LinkText`（文字按钮）。日期 / 距离 / 时长的显示在 `qml/theme/Fmt.qml`（单例）。`Toast` 可以带一个文字按钮（删除后的"撤销"）。

0.8.8：`TopBar`（顶栏：⋯ 页面胶囊 + 泡泡、↩、保存状态、列表 | 头像胶囊）、`SplitBud`（分裂泡泡的一颗，从 `LayerBubbles` 抽出来，顶栏 ⋯ 和图层泡泡共用）、`AvatarMenu`（头像菜单）、`PlanListPanel`（"我的旅程"列表，方案 B）、`CommandPalette`（Ctrl K，方案 B；打分在 C++ `src/app/commands.*`）、`RoundButton`（圆形玻璃按钮：↩、地球 / 平面）、`TpIcon`（照 Electron SVG 用 Canvas 画的线条图标）。

0.8.9：`PlanEditor`（站点编辑器，方案 B：计划信息卡片 + 站点时间线；逻辑在 C++ `src/app/planeditor.*`，QML 里叫 `editor`；宽窗口是右侧面板，≤ 768 是底部抽屉）、`EditOverlay`（地图上的草稿标记（能拖动）、搜索结果的编号点、点选模式的十字光标和虚线、我的位置蓝点 + 精度圈；在 FlatMap 里）、`StylePopover`（样式浮层，方案 B：颜色、外形、图标）、`ColorWheel`（自定义颜色）、`MarkerShape`（画一颗小标记预览）、`DateField`（日期输入 + 日历）、`TpField`（单行 / 多行输入框，输入时外面的值不覆盖）、`DrawerGrip`（底部抽屉的把手：拖动 / 双击切换高度）。`TopBar` 加"新建计划"按钮，`PlanSheet` 加"编辑"按钮，`TpIcon` 加 plus / minus / locate / edit / grip / up / trash / pick / coord / check。
