# src/platform

Windows 专属：托盘、单实例、回收站、凭据管理器/DPAPI、系统定位、窗口状态、语音输入（Win+H）。

7.0.0-b 原型：`graphicsbackend.*`（Vulkan 优先、OpenGL 退回，选择两套 maplibre 之一）、`procmem.*`（进程内存读数，内存测试用）。

0.4.0：`paths.*`（设置、默认数据、缓存、日志放哪，见文件头）、`singleinstance.*`（单实例，QLocalServer）、`tray.*`（托盘，Win32 Shell_NotifyIcon 自写；非 Windows 上没有托盘）。

0.5.1：`crashhandler.*`（崩溃时写 errors.log、小 .dmp、"上次崩溃"记号）、`nativedialog.*`（TaskDialog 系统对话框，显卡出错 / 卡住时用）、`watchdog.*`（卡住检测：心跳 + 看门狗线程）。

0.5.2：`crashhandler.*` 加 `sehFilter`（`TpApplication::notify` 外层 SEH 用）、`checkFilter`（看门狗每秒检查过滤器是否被换掉）、`status`、后台线程崩溃测试；异常码规则在 `src/app/crashcodes.h`。
