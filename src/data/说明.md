# src/data

数据层（0.3.0 起）：`jsonvalue` / `jsonio`（自写 JSON 读写，按 JS 规则）、`datafile`（data.js 包装）、`datastore`（加载、保存流程、外部修改检测、历史、AI 备份）。编成静态库 `tp_data`，程序和 tests 共用。原定内容：data.js 读写（保持键顺序、按 JS JSON.stringify 规则输出、保留不认识的字段）、data.backup.js、临时文件+改名、回读比对、.history 按天备份、哈希冲突检测、3 秒外部修改检测、照片与缩略图缓存。阶段 ①。

0.5.0 加：`savescheduler`（自动保存节拍，停手 0.8 秒）、`undostack`（撤销 / 重做，30 步，写时复制快照）、`backup`（手动 / 自动备份到指定文件夹）、`trdata.h`（数据层显示给用户的文字用 `trd("中文")`，走翻译词典）。

0.6.0 加：`nativeformat`（原生版的 travel.json：文件名、版本规则、空数据、写法）、`lockfile`（`.lock`，两份原生版同时打开时后开的只读）、`electronimport`（从 Electron 版导入：转换、合并、复制照片、回滚）。`datastore` 改成读写 travel.json；`datafile`（data.js 外壳）只在导入时读。格式说明见 `claude/数据格式.md`。

0.7.0 加（照片）：`exif`（自写 EXIF：JPEG / PNG / WebP / HEIC，时区、位置、海拔、方向、相机、镜头、拍摄参数、尺寸）、`photolib`（导入：猜计划站点、查重复、复制和回滚；清理：扫描、三道保护、回收站）——这两个在 `tp_data`；`thumbcache`（按方向摆正读图、缩略图缓存）、`photorotate`（旋转、.originals）——要 Qt Gui，单独编成 `tp_photo`。说明见 `claude/数据格式.md` §8。
