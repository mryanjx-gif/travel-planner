# src/map

平面地图（maplibre-native-qt）和地球（QQuickRhiItem + 自写着色器）。阶段 ②、③。

0.8.0 起的平面地图（为什么这样做见 claude/v0.8.0记录.md §2）：
- `geo.*`：墨卡托投影、相机（中心 + 缩放 + 窗口大小）、像素 ↔ 经纬度、按范围缩放、动态最小缩放、飞行曲线（maplibre-gl flyTo）。
- `night.*`：卫星图上的昼夜阴影——48 条互不重叠的 GeoJSON 细带（`stripes`，每条一种透明度）拼出 Electron 的暮光过渡，每处只画一层（0.8.7 起；原来的叠层 `bands` 只留给单元测试对照）。
- `unlock.*`："已解锁"上色，照搬 Electron computeUnlocked（固定次序，tst_map 和 Electron 逐个省对照）。
- `tripdata.*`：从内存里的数据生成路线 / 站点 GeoJSON（大圆弧、道路折线照搬 Electron）。
- `markers.*`（0.8.2）：标记样式（stopStyle）、尺寸、合并（5 层）、合并圆圈的 OKLab 平均色、错开。
- `roads.*`（0.8.4）：道路路线——polyline 编解码、抽稀、legKey、"还没算"的段、写回 leg、OSRM 的网址和返回值（照搬 Electron，tst_map 用 Electron 原样代码对照）。
- 上面六个是静态库 `tp_map`（只依赖 Qt Core 和数据层），单元测试 `tests/tst_map.cpp`。
- `markerimages.*`（0.8.2）：QML 的 `image://marker/…`，QPainter 照 Electron 的 CSS / SVG 画标记、合并圆圈、聚焦光晕。`msicons.h`：图标名 → Material Symbols 码位。
- `markerlayer.*`（0.8.2）：QML 里的 `mapc.markers`。标记和圆圈两个列表模型、每次相机变化时的位置、合并 / 错开的时机、悬停渐变、选中和聚焦。0.8.4 起线条的高亮和变淡也在这里（和标记同一个渐变）。
- `mapcontroller.*`：QML 里的 `mapc`。管相机（拖动惯性、滚轮缓动、飞行）、底图、交给 maplibre 的数据；骨架样式文件（只有在线底图网址）写在 `<缓存>\map\style-v3.json`（0.8.4：transition 0），其余都在内存里经 `qml/FlatMap.qml` 的 SourceParameter / LayerParameter 交给地图。

地球（阶段 ③）：`globeitem.*`、`globetiles.*`、`globeraster.*`、`globegeom.*`、`sun.h`。
0.9.0（为什么这样做见 claude/v0.9.0记录.md）：
- `globegeom.*`（tp_map，只依赖 Qt Core）：相机（和渲染那边同一个透视、上方向）、投影 / 拾取、背面判断、按视野选瓦片（四叉树，按屏幕上的边长分级，超预算整体放粗）、和平面缩放级别的换算（屏幕中心比例尺相同）、最远距离（Electron updateMinZoom 的球形）。单元测试在 tst_map。
- `globetiles.*`：瓦片调度。卫星图经本机瓦片服务的 `requestTile`（同一份硬盘缓存、离线开关、失败计数），后台解码并算好 mipmap；已解锁和卫星图的垫底简图由 `globeraster` 画；显卡上一个 256×256×192 层的纹理数组，按"最近没用到"换出；没到的块用子块 / 上一级 / 垫底的 z1 顶着；离开地球全部丢掉。
- `globeraster.*`：后台线程读省界（adm1 面、adm0 国界线），按块画"已解锁"（和 FlatMap.qml 的已解锁图层同样的颜色、线宽、圆点）和卫星图的垫底简图；缩得很小时用抽稀过的路径。
- `globeitem.*`：QQuickRhiItem。画星空 → 底球（纯色 + 两极 + 昼夜）→ 瓦片（一块 33×33 网格实例化，顶点着色器把墨卡托换成球面）。相机：拖动惯性、滚轮缓动、以鼠标处为中心缩放（照平面的手感）。底图只有卫星图 / 已解锁（PO 2026-11-06）。

0.8.4：`mapcontroller` 把路线分成三份交给地图（平时 / 鼠标碰到的高亮层 / 选中的计划），线条透明度每帧由 C++ 算；鼠标碰到线自己算（`lineAt`：到线的距离 ≤ 4 + 线宽 / 2，最上面的那条）。

0.8.7：`plans.*`（tp_map）——计划的排序、筛选（状态 / 类型 / 区域 / 隐藏、revealPlan）、"此刻"（pickNow / todayItems / todos / notices）、简易面板的内容、改数据的几个操作，照搬 Electron，tst_map 用 Electron 原样代码对照（`tests/golden/plans.json`）。`TripData::build` 加了"哪些计划要画"（筛选）；"已解锁"照样用全部已完成计划。`mapcontroller.cpp` 拆成 `mapcontroller.cpp`（构造、样式、瓦片、底图、数据、昼夜）、`mapcontroller_camera.cpp`（相机；0.8.7 的 `setInsets` / `flyToPlan` / `frameTrip` / `panToVisible`，让开浮在地图上的面板）、`mapcontroller_lines.cpp`（线条命中）、`mapcontroller_unlock.cpp`（手动标记），共用的小东西在 `mapcontroller_p.h`。

0.8.9：`planedit.*`（tp_map）——站点编辑器的纯逻辑：新计划 / 新站点、检查、区域建议（Electron suggestRegion 原样）、各种改法、legs 跟着站点走、分段和总里程、今天所在的站点；不碰界面和网络（那些在 `src/app/planeditor.*`）。`mapcontroller_edit.cpp`：草稿（正在编辑的计划单独一个 geojson 源 + QML 能拖动的标记，平时那一层不画它、其余计划变淡）、按点框住（`fitPoints`）、`anyVisible`、比例尺、离开"已解锁"、飞到某个国家（`fitCountry`，用 `unlock::countryBox`）。`markerimages` 能画草稿样子的标记（虚线边，图片 id 后面加 `/d`）。

0.9.5（地球上的内容，为什么这样做见 claude/v0.9.5记录.md、技术选型.md §7k）：
- `globeroutes.*`（tp_map）：从 TripData 的路线生成三维折线（细分到 ≤ 1°，飞行段按 段长 × 12%、最高 1500 km 抬起）；投到屏幕、去掉被球挡住的部分（`screenRuns`）、到线的距离（碰线）、交通小图标排时间（`planVehicle` / `vehicleAt` / `pointAlong`）。单元测试在 tst_map。
- `globegeom.*` 加：`Camera::occluded`（球外的点也能判断）、地平线、背面渐隐 / 边缘变小（`limbOf`）、极点附近不抽搐的以鼠标为中心缩放（`zoomAnchorCenter`）、相机距离的对数插值、中心的球面插值。
- `globeops.h`：GlobeItem 交给 MapController 的相机接口；`mapcontroller_globe.cpp`：在地球上时标记按地球摆、碰线、定位 / 飞过去转给地球（超过 5.5 级换平面）。
- `markerlayer.*` 能换投影（`setGlobeView`）；`globeitem.*` 多画一遍线（`shaders/globeline.*`）、交通小图标、城市灯光只在最远时显示、滚轮缩放按相机距离插值。

0.11.1：`photomap`（照片连上计划和站点、合并、相册的行；单元测试用）、`photolayer`（照片模式的标记，只画看得见的）。
