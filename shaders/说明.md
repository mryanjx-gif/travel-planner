# shaders

着色器源码（GLSL 440），编译时由 qt_add_shaders 调用 qsb 生成 .qsb；运行时只加载 .qsb，不链接 Qt Shader Tools。

7.0.0-b：`globe.vert/.frag`（地球球体、昼夜）、`sky.vert/.frag`（星空、大气外光）、`glass.vert/.frag`（液态玻璃，移植自 Electron liquidglass.js，0.12.0 起支持粘连和标准玻璃）。
0.9.0：`globe.vert/.frag` 改成底球（纯色 + 两极 + 昼夜 + 光边，不再取纹理）；新的 `globetile.vert/.frag` 画瓦片（纹理数组 sampler2DArray，所以单独一组 qt_add_shaders，GLSL 只出 300 es / 330 / 410 / 440）。
0.9.5：`globeline.vert/.frag` 画地球上的路线（顶点在 CPU 上已经投到屏幕、是 NDC；圆头、虚线、抗锯齿在片元着色器里算），和瓦片同一组（GLSL 300 es / 330 以上）。
